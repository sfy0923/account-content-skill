合成行为检查涵盖：

1. 少量解决方案型选题，七项分数与依据、数量不足如实报告、历史范围边界。
2. 决定性收费事实不足时，追问原因和授权约定，不编造收费解释。
3. 已确认方案下45秒完整稿，覆盖台词、分段时间、画面动作、字幕、剪辑与估算说明，不套三分钟默认。
4. 只改一句的近邻请求，保持范围，不重启定位、选题和整稿。
5. 复审撤回错误意见，识别新增亲历与保证，推荐最好版本，允许零修改。
6. 不同领域的留出策划任务，区分事实、原话和编辑判断，不捏造资历、授权或已完成访谈。

45秒样本的实际台词为142个汉字，采用每分钟210字的假设，口播约40.6秒，加约4秒非并行停顿与收尾，计算约44.6秒。该结果只验证文本估算一致性，不是真人实测。

样本未参与模块写作；执行者只读取候选 Skill 和对应原始请求。执行与评估分开，但共享文件系统，属于上下文与材料访问约束，不是操作系统隔离。评分、原始测试输入和执行记录保留本地，不随公开仓库发布。
