# 同行视频分析与行业检索

本模块在项目材料不足时补充外部题源，也支持用户单独要求分析视频、检索行业或提炼可迁移方法。同行材料不能替代当前人物的访谈、真实业务、亲历案例和授权。

## 1. 何时进入，何时返回

- 新项目尚未取得可用的策划、访谈稿或访谈录音，但行业与账号身份已知，且当前任务需要开发内容方向时，自动先寻找并分析一条相关同行作品，再进入用户要求的后续阶段。
- 缺少录音但已有足够的书面访谈或策划，不算题源缺失；先判断材料能否支持本题，不机械补做同行研究。
- 已有足够材料，或用户只改一句、复核一题、处理局部审核意见时，不重启本模块。
- 用户提供可读的同行链接或文件时，优先分析该作品，不因默认检索流程再找一条代替它。
- 用户只要求视频分析时，交付分析后结束；只要求选题时，研究后进入选题模块，不自动写完整脚本。

先恢复已确认的行业、实际业务、账号角色、受众、平台、目的和资源。未知项如实记录；只追问会改变本次检索对象、迁移判断或授权的缺口。

只有视频而目标行业不明时，可以先描述原片可见内容，但不能将原作者行业或身份自动设为当前账号背景。平台未明确且上下文也不能确定时，先确认平台；不声称研究了未访问的平台。

## 2. 先做小词图，再寻找一条代表作品

材料补充以完成当前任务为目标。先做小型起始词图和少量有目的的检索组合，不默认扩成全行业普查。

起始词图围绕当前业务选择必要维度：

- 行业总称、实际产品或服务及已知别称。
- 买方、卖方、使用者或其他本题相关角色。
- 需求出现、比较、判断、交易、交付或售后中的具体节点。
- 价格、风险、时间、信任、误解等与节点有关的问题。
- 内容形式、可展示动作及必要的地区或规则差异。

每个词注明来源：用户提供、平台实际看到，或根据业务结构推导的候选。尚未访问平台的词记“起始词待平台验证”，不能称为已发现的热门词。

将可执行的短搜索句编号为 Q01、Q02……，记录想找什么、组合维度和优先级。项目已有Q编号时沿用并顺延，不覆盖旧记录，不做无意义全排列。

按相关性和材料可读性选择一条代表作品：它应与当前业务节点、目标观众或表达任务有关，且有可回查入口。同行不必具有同样的流量，但主体资源、资质和制作条件的差异必须记录。

互动数只作为检索优先级信号。不能因为点赞较多，就称为爆款、推断留存或成交效果，或认定适合当前账号。

## 3. 执行检索与记录来源

有指定平台且可访问时，优先执行平台原生搜索。每条Q记录计划搜索句、实际输入词、平台、日期、筛选或排序及执行状态。

状态使用以下含义，不把未执行写成已完成：

- 已搜索：实际执行过，并记录取得范围。
- 结果高度重复而合并：与哪些Q重合、合并到哪里。
- 覆盖充分暂未搜索：当前任务已获得足够材料，保留未执行记录。
- 平台限制未搜索：访问、登录或能力限制及其影响。
- 无相关结果：执行后未获得与当前任务相关的作品。

去重后的作品编号为 V01、V02……。记录作者、标题或可见描述、稳定链接或回查路径、发布时间（可见时）、对应Q及核对程度。项目已有V编号时沿用并顺延。

同一作品被多个Q发现，保留一个V编号并附全部Q号。搜索中新发现的叫法、话题和组合单列“下一轮补词”，不倒填成原始词图已有内容。

站外搜索可以帮助发现作品链接，但须标“站外发现”，区分搜索摘要、平台搜索页和实际作品页。站外索引结果不能冒充平台原生搜索或作品完整核验。

平台访问受限时，说明已完成和未完成范围，继续不依赖该平台的部分。无法取得任何可用作品时，交付检索记录和最少补充材料，不编造原片分析；已有可靠公共资料仍可支持独立的研究型候选。

## 4. 根据实际能力取得原片

按以下顺序核对，不把某个付费接口或本机软件作为通用前提：

1. 确认作者、标题、链接和当前取得的文件对应同一条作品。
2. 优先使用可用的连接器、已配置提取工具或浏览器只读查看；有已授权登录会话时在该授权范围内使用。
3. 能合法取得视频文件时，验证可播放、实际时长、是否完整及是否有音轨；记录取得范围。下载或录屏只是可选途径，不能在未取得时声称完成。
4. 有可用音轨和转写能力时提取人声并转写，再核对关键时间点；有能力查看画面时同步检查字幕、动作、镜头和声音。
5. 所需登录、权限、收费工具或用户材料不可用时，说明具体限制，按已取得材料降级继续。

不点赞、关注、评论、私信、购买或发布，不绕过平台访问限制。工具未配置时不擅自购买服务，不把安装某个商业工具列为所有使用者必须完成的步骤。

登记表至少保留：来源入口、取得日期、作者与标题、时长、音频/画面/字幕取得情况、实际时间范围、评论样本范围、可见互动信号及待核验信息。

| 材料范围 | 可以交付 | 必须说明的限制 |
| --- | --- | --- |
| 音画完整可核对 | 完整逐字记录与视听结构分析 | 作者说法仍需按性质核验 |
| 部分视频或音轨 | 部分逐字记录与取得范围内的分析 | 标明起止范围，不能称已看完整片 |
| 仅完整音轨 | 人声逐字记录与声音分析 | 画面、字幕、动作和剪辑画面未核对 |
| 仅字幕、截图或页面文字 | 可见文字与画面分析 | 原声未取得，不能冒充口播逐字稿 |
| 无法读取 | 卡点、检索记录和补充材料要求 | 不交虚构的原片内容或效果判断 |

## 5. 逐字记录与画面核对

逐字记录用于保留证据，不替作者润色、补逻辑或纠错。按原片顺序记录可辨识的人声，附说话人和时间范围；时间只能估算时标“约”。

- 保留重复、口误和语气词；听不清处写“[听不清，约时间点]”，不凭字幕或常识猜词。
- 屏幕文字单列。与口播不一致时保留两者，不能把字幕补入未听清的人声。
- 关键动作、镜头、背景声和剪辑观察另列，不混入人物原话。
- 页面提示、评论、弹幕或AI摘要各自注明来源，不冒充作者口播。
- 音轨不完整时使用“原视频逐字稿（部分）”；无原声时使用“原声未取得”，只交可见材料记录。

有原片文件时保留原件和取得范围，整理稿不能覆盖原件。任何完整度判断都以实际取得和核对结果为准。

## 6. 从证据分析，避免因果猜测升级

先用普通语言说明原片讲给谁、讲了什么、核心观点或展示结果、怎样推进以及可见的行动引导。观众或目的由内容推断时明确标“推断”。

只分析本片真正重要的选题、开头、结构、证据、表达或视听动作，不机械点评所有项目。每个重要判断保留：

> 时间点或来源位置 → 原话／画面事实 → 可能起到的作用 → 判断理由 → 其他解释或不确定性。

区分“作者这样说”“取得材料直接展示”“我们的解释”和“效果猜测”。没有留存、播放或成交数据时，不能把某句台词或剪辑写成这些效果的原因；没有取得评论时不分析评论区。

数字、价格、政策、资质、金融、医疗、法律、安全等影响核心结论的内容，按适用时间和范围核验可靠一手来源。未核验时保留原说法的来源属性，缩小或停止依赖它的结论，不能只加“可能”继续复用失实观点。

## 7. 方法与观点迁移

真正值得参考的做法整理为短方法卡：

- 原片位置、原话或画面，以及具体做了什么。
- 为什么可能有效、尚存哪些其他解释。
- 对应当前账号的用户问题、业务节点和内容目的。
- 可以改成的结构、提问、动作或展示。
- 所需的真实材料、解释能力和制作条件。
- 不能照搬的身份、经历、客户、资源、承诺与结果。
- 后续可观察的验证信号。

观点另标证据属性：现场展示、可靠公开资料、作者口述、评论猜测或未核实。当前账号可以借问题意识和解释框架，不能将原作者经历改名为本人的故事。

同行作品只补外部题源，不补客户事实。当前人物的业务、收费、资质、案例、语言习惯和经验范围仍按本项目资料确认；题目经验状态继续依规划与选题模块判断。

只有观众问题有依据、人物能解释、账号能提供必要证据且主要制作条件能承接，才建议复用。缺关键条件时，方法卡保留待验证，不称已完成账号适配。

## 8. 研究阶段的双层评价

研究候选使用“题目潜力分＋当前落地准备度”，用于决定先研究、补证或打磨什么。进入正式选题后，仍按[选题模块](topics.md)的七项权重5／4／2／3／3／2／1、90分门槛和硬门槛复核。研究潜力85分不能换算成正式入选90分；两阶段分数不能混加、替代或用名称省略其用途。

### 题目潜力

各项0—5分，记录具体依据，满分100：

| 研究评分项 | 权重 |
| --- | ---: |
| 观众驱动力与后果清晰度 | ×4 |
| 场景具体性与代入 | ×4 |
| 具体问题与观看理由，含自然反差 | ×3 |
| 核心机制清晰度 | ×3 |
| IP业务潜力与受众关系 | ×3 |
| 核心机制依据与可解释性 | ×2 |
| 平台参考信号 | ×1 |

潜力总分＝各项原始分乘权重后相加－按选题模块判定的重复扣分。语义重复或相邻未改好仍不能进入正式入选；硬事实、授权和适配缺口不能由分数抵扣。分档为85—100优先研究／打磨、75—84值得继续、65—74改造后再审、0—64暂缓。分档只指研究优先级，不是生产许可或效果预测。

未知项标“待评”，不填0或凭印象补满分；只报告已评项加权小计和其满分，不给确定总分或跨不同缺项的排名。例如缺平台互动材料时，写“其余六项小计X／95，平台项待评，总分待评”，不直接降档、不把X／95改写成X／100。已有数字只证明页面信号存在，不能证明留存、成交或方法因果；信号与当前受众、任务是否相关也须解释。

### 当前落地准备度

五项各0—5分，等权换算：真实业务匹配、可回查证据、可展示场景／设备、人物表达与制作条件、合规／授权边界。各项乘4后相加，满分100；任一未知项仍标待评、列资料缺口，不合成确定总分。

状态按实际条件判，不以百分比自动升级：必要条件齐全为“充分”；核心已成立而非关键执行资料待补为“部分”；核心事实、必要授权或主要制作能力缺失为“不足”。同行拥有的条件不能算作本账号准备齐全。

每个研究候选同时记录两层分项、依据、缺口和状态；不满足时可保留方向。若没有题目具备足够材料，明确“目前没有材料足够的首选题”。本轮只要视频分析时，不为了凑表强行生成或评分选题。

## 9. 源词映射与选题交接

从原片提取可回查的标题词、话题词、口播/字幕词、动作、利益点、冲突或结果词，形成：

> 原片源词及位置 → Q检索组合 → V代表作品 → 可迁移机制 → K核心内容。

未搜索或未核对的环节标计划或待验证；平台参考信号不能充当核心事实依据。

沿用项目现有核心内容ID及历史索引。新核心持续编号为K或项目已有格式；不要另建一套编号重复登记。同一结论仅更换品类、人物或标题，仍按选题模块判重复。

进入选题模块时交接本题受众、唯一机制或结论、观看理由、完整具体内容、Q/V来源、材料核验属性、当前人物可讲范围及缺口，以及研究潜力和准备度记录。正式选题评分依选题模块执行，本模块不另设正式入选门槛；正式评分重新核对当前材料，不沿用研究分数冒充复核。

选题判断与生产准备分别记录。高评价不能补足事实、授权或拍摄条件；核心条件不足时保留待补候选，不计作已成立的正式合格题。

用户只要看方向时，可先交小批预选并列待补项；缺真实故事与模拟授权时，不用同行故事替换人名凑故事题。进入脚本仍沿用知识答案、方案和整稿的真实确认进度。

## 10. 保存与交付

按任务需要交付“视频分析与复用”“词图与检索记录”“选题与评分”，可以分文件，也可以作为同一项目记录的清晰章节。无需保存时直接给可复制结果，不声称已建目录或更新索引。

保存位置使用用户指定的项目目录；未指定时采用当前工作区允许的交付位置。不把任何使用者的个人目录写成通用默认，不静默覆盖同名文件。

保存后核对文件、链接、来源和核心ID，更新获准维护的项目索引。用户要求副本时再复制，并核对两份一致；不能在未实际检查时报告同步成功。

原片、逐字记录、评论样本与客户材料留在获准的任务资料范围。公开分享Skill时只发布通用规则、模板和适当匿名的验证说明，不自动上传研究原件或客户项目内容。

最终说明本轮实际取得范围、完成阶段、可迁移做法、关键限制及下一步必要资料；无法取得原声或完成平台搜索时如实报告，不把局部研究包装成完整验证。
