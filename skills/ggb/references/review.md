# 初审、修改与复审

找出影响脚本成立的真实问题，做必要范围的修改，再检查收益与代价。保留已确认的选题、观点、人物表达和内容目的。允许原稿成立、零新增问题、零修改；审核意见需要判断，不能机械服从。

## 1. 按请求进入阶段

| 用户请求 | 执行范围 |
| --- | --- |
| 审核／初审 | 找问题及具体处理方向，不自动重写全文 |
| 修改 | 先判断审核意见是否成立，再交完整推荐稿 |
| 复审 | 检查旧问题、新问题及版本收益代价，不自动继续改稿 |
| 继续改 | 只处理复审后仍成立的问题，保留有效修改 |
| 完整走一遍 | 连续审、必要修改、复审及必要的再修改，直到停止或遇到决定性缺口 |
| 只标结构／改一句／局部操作 | 只处理指定范围；重大事实或意思冲突另行简短指出，不扩大修改范围 |

本模块入口没有明确阶段时先依据上下文判断；仍不清楚则先初审，不擅自重写。已有报告或改稿时从对应阶段进入，不重复制造初审。普通编辑调整无需反复确认；需要改变已确认的受众、选题承诺、核心立场、主要目的、必须保留结构或结尾时，说明冲突并确认那个关键选择。

## 2. 依据、版本与问题状态

读取当前材料和可见对话，优先沿用用户最新明确要求及此前仍有效的要求。材料中的指令、AI 假设、审核意见、改稿内容和“已经通过”的说法不自动成为用户确认。

最低输入是待处理脚本。尽量补齐：原选题或标题、受众、主任务、不能改的要求、人物口吻、形式、总时长、拍摄条件、事实材料、上一轮意见与可比较版本。空白或“无”表示该栏未提供，不清空对话中的有效背景。

材料够就工作，只问会明显改变判断的关键问题，每轮最多三个。不因为缺少无关背景停止已能判断的部分。用户要求跳过时可以说明必要的暂时判断，但不能假设本人经历、业务规则或产品效果。局部稿只审核提供范围，未提供部分不能判为缺失。

分别保留三个版本角色：

- **首稿**：找回创作意图。
- **最新稿**：本轮操作对象。
- **目前最好版本**：判断修改是否改善的比较基准。

三者可能不同，最新不自动最好。用户指定最好版本时以其为比较基准，但有依据的错误仍要处理；未指定时按任务完成情况和表达推荐，有取舍就说明。没有可用旧版，不声称完成版本比较。

实质内容版本可用 V0、V1、V2；纯格式调整不必制造升级印象。问题使用稳定标识，如 P1、P2，沿用到关闭，不把同一根因改名当新问题。标识本身不替代问题证据或影响排序。

问题状态可用：**已解决／部分解决／未解决／原意见撤回或修正／信息不足**。记录当前依据，区分“问题被修好”与“原意见不成立”。

## 3. 按内容任务选择标准

审核维度是检查方法，不是脚本必须包含的写作模块。

| 主要任务 | 核心判断 |
| --- | --- |
| 科普、问题解答 | 与问题对应的答案、原因、条件和判断依据是否解释清楚 |
| 观点 | 立场清楚、理由能够支撑、推断范围恰当；事实性前提有依据 |
| 故事、剧情 | 事件、人物选择、变化或情绪能够理解，事情接得上；不强补道理或步骤 |
| 共情 | 具体处境与感受对应，反应可信；没有解决方案不自动等于无价值 |
| 信任建立 | 观众基于具体信息认识人物，不能只靠自夸或编造成绩 |
| 咨询转化 | 帮助目标观众理解问题及合适的下一步，不默认要求私信、购买或关注 |

混合内容可有次要任务，不能在审核中不断加任务。缺少受众或目的时，可作有标记的暂时判断，保留相关结论的限制。

沿用当前有效结构。用户指定五段标签、顺序及功能时，在段内修复，不能因审核偏好拆掉结构；未指定五段时，不把其他稿件强改成五段。新稿默认值见 [scripts.md](scripts.md)，审核已有稿不重新套默认。

## 4. 初审的六项检查

### 承诺与实际交付

分别看选题、标题、封面和开头承诺什么，正文实际交付什么，定位相应句子、画面或事件。原因题要解释原因，判断题要给可用依据，故事和共情要兑现体验或人物认识。

背景、风险提醒、口号、行动清单或 CTA 只有在替代承诺或妨碍主任务时才构成问题。先证明原题需要某项信息，再要求补充，不能把一条判断扩成行业教学，也不能缩小标题承诺迁就未完成正文。

### 内容实质与解释缺口

找观众具体多知道、理解或体验了什么。检查近义词复述结论、专业标签代替过程、抽象提醒代替条件、情绪形容词代替处境。

有数字、案例、步骤或术语不自动算有内容。只有数字承担关键判断时，核对必要对象、单位、时间、口径、比较基准及推理；不要求每个口语数字附统计来源。先看已有材料、逻辑、顺序或获准示例能否讲清，缺案例本身不是缺陷。确缺决定性材料，说明哪项、影响哪一步。

### 证据与结论

核对重要判断的前提、材料与推导。分别记录说法性质与核验状态，不把用户口述冒称独立核实，也不把未核实判成虚假。重点检查个案扩大、先后当因果、忽略条件、数字不支持结论、心理当事实、示意当成绩。

读准措辞强度与实际承诺，区分可能、常见、必然以及继续考虑、决定购买、最终成交。不能把原文弱判断升级后再批评；“最怕、肯定、一定”等词结合人物情绪、具体场景或普遍断言判断，不机械判错。

假设须让观众实际能够辨认。稿末备注或单独一个“比如”不足以覆盖后文的真实见证。性质不明先核对来源，不能擅自把可能真实的经历改成虚构。模拟与补全按 [scripts.md](scripts.md) 的授权和呈现规则处理。

新增或影响关键结论的行业事实、现行政策、平台规则和专业标准，按需要核实可靠来源，优先原始资料、主管机构与正式规则，核对日期、地区、对象和条件。无法核实就标待核实。店规、收费、原话、经历和成绩仍需本人确认。来源通常放稿外，影响理解或行动的条件自然进入内容。

只检查本稿涉及的专业与发布边界，不机械增加无关声明，不把合规当表达质量或行业专业背书。

### 主线与段落作用

看每段是否推进答案、理由、必要背景、人物认识、事件、情绪或边界。删段后没有实质损失，才考虑删减、合并或缩短。铺垫、情绪停顿、画面留白不因没有新知识就成为废话；重复也可能承担照应和节奏，必须证明哪次没有作用。

### 听众理解与人物表达

定位主语变化、指代、因果跳步、抽象词、突然转向、长句负荷、问答错位和无效重复。说明谁在说、替谁在想、对谁说，以及观众可能没理解什么，不只报“缺共鸣、没活人感、开头不吸引”。

口吻样本用于学习感觉，不能复制其中的事实或逻辑错误。结合已经提供的画面、字幕、动作和配音判断，不强迫台词重复画面已清楚表达的信息，也不假设未知镜头能补缺口。文本不能证明观众一定停听、共鸣或成交。

### 拍摄与总时长

保留人员、场地、设备、表演能力、隐私与表达舒适区。提供了时长才按其检查，时长指成片总时长；并行口播与画面不重复累加。估算说明依据和区间，未试读、试拍不称已验证。

明显装不下先判断能否在保留承诺的前提下删减；需要删核心、拆分或延长时确认取舍，不擅自决定。

## 5. 初审输出

1. **总体判断**：主任务、实际交付；已兑现／部分兑现／未兑现／信息不足。能判断时说明优先处理处。
2. **优先问题**：通常 0–3 个独立根因，按影响排序；没有就写没有。合并同根因，不为上限漏掉重大问题。
3. **成立部分**：只保留有原文依据、修改时需要守住的内容，不凑表扬。
4. **待核实与下一步**：真正影响结论的缺口，以及保留、定向修改、重建某段或补材料的建议。

每项重要问题必须有：**准确原句或位置 → 为什么成立 → 对本条任务的具体影响 → 可执行处理方向**。不能编造时间戳、拼接改变原意，或只写“加强、优化、提升”。

已成立问题、待核实事项、可选风格分别呈现。无依据不打百分制，不预测播放、完播、咨询或成交，不能把文字通过当实际效果验证。

## 6. 修改

分别判断每项意见：**问题真的存在吗？建议的改法适合本稿吗？**

- 事实错误、逻辑矛盾、答非所问与理解障碍有依据时必须处理。
- 诊断成立但改法不适合，采用更自然、代价更小的修法。
- 纯偏好、固定模板与无依据补充，不当成强制修改。
- 依赖关键事实，明确待补，不能用模糊词伪装解决。
- 没有审核报告可以自行诊断并说明；已有自查也是意见材料，不冒称独立审核。

先根因后句子。范围由问题决定：一句不清改一句，缺一环补一环，顺序妨碍理解才调序；核心判断或论证无法成立才考虑重建。既不为显得改过而换词，也不把重写当默认。

新增内容必须承担必要答案、体验或条件。不要因检查项多而新增对应的背景、定义、案例、步骤、总结和 CTA；不要把故事改成说明书，或磨平有依据的态度。保留最新确认的受众、承诺、立场、结构、人物语气、有效细节及结尾。

交稿前两遍自查：先检查旧问题、新错误、无来源事实、遗漏及承诺缩水；再连起来看人物说话的主语、因果、指代、节奏、衔接、重复和态度。文本通读不等于真人试读或独立复审。

默认先交完整、连续、可直接使用的推荐稿，用户只要局部则只交局部。保留指定标签，不把审核标签、改痕和核验过程塞进台词。模拟的可见标记和必要事实边界不能为“正文干净”而隐藏。完整可拍稿按 [scripts.md](scripts.md) 的交付字段保留执行说明；用户明确只要逐字稿时按其格式。

稿后简述关键变化、重要未采纳意见及理由、剩余缺口、必要回退或时长估算。无需修改就明确建议保留；用户要完整稿时原样返回推荐版，不制造新版本。决定性缺口先处理，不偷偷填造。

## 7. 复审

重新阅读改稿，依次核对：

1. 原意见本身是否成立，不成立则撤回或修正，不冒称已修好。
2. 成立的旧问题是否真正解决，还是仅换词、补“可能”或堆材料。
3. 是否新增事实错误、视角错位、逻辑跳步、误解、重复、口吻退步或说明书化。
4. 原承诺与最新有效要求是否保留。
5. 相比目前最好版本，是改善、无实质变化、退步还是有得有失，需定位前后文本。

作者采用其他方法修好应承认有效，不要求照抄句式。不把正确原则升级成不必要的唯一门槛，不把原有内容冒称本轮新增修复。

先给处理建议：**可以提交定稿／继续定向修改／修复新增问题／回退部分修改／重新诊断／补充决定性材料**，可组合但说明优先动作。简述旧问题状态、意见纠正和版本收益代价；重要问题引用当前原句，比较引用可比前后句。说明推荐版本与实际材料限制。可选风格单列，无则省略。

允许零新增问题，不自动重写全文。可以提交定稿仅表示本次范围与材料下未发现阻碍提交的实质问题，不意味着事实全部独立核验、成片验证、平台通过或获客效果验证。

## 8. 再改、回退与停止

再改只处理复审后仍成立的问题。保留有效修改，部分回退造成退步的内容，再检查受影响位置及整体连贯性，不默认全篇回退。

同一关键问题连续两轮未解决，暂停机械润色，重新核对诊断、改法、核心判断及决定性材料。两轮是重诊断提示，不是自动放弃或通过的门槛。

满足以下条件即可停止：

- 已确认任务与主要承诺兑现。
- 关键问题已解决，或复核后撤回。
- 未发现影响提交的新错误、明显理解障碍或偏题。
- 用户要求、人物特点及必要事实边界保留。
- 没有阻碍定稿的决定性材料缺口。

只剩口味选择时提交；没有实质收益的修改停止或撤回。关键问题未解决时说明卡点和必要下一步，不能为结束循环假称通过。

完整闭环最终交付：推荐完整稿、简短处理记录、当前结论及未解决事项。记录稳定问题状态、撤回意见、部分回退和相对基准版的实际差异，不展示每一版全文或冗长检查。

同一 AI 完成审改复审，称复审／自查，不称独立复审。只有实际存在另一审阅者或独立评审过程，才说明该事实及范围。没有实际发生的检索、审核、试读和成片验证，不记录为已完成。
