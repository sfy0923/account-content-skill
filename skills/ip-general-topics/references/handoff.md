# 共用交接与确认

每次从实际对话或上层项目记录恢复，只交接当前动作有关内容。不是要求用户填写的表。没有独立交接卡但上下文信息充分时直接整理，不因此阻断。独立调用和 GGB 调用使用同一含义。

| 信息组 | 记录内容 |
| --- | --- |
| 本轮请求 | 调用方；动作；内容分支与适用标准；数量；修改范围；需要输出全部还是局部；最终还欠哪些动作 |
| 当前对象 | 项目／账号／人物身份；实际业务；主要观众与处境；本条目的 |
| 有效要求 | 已选题与核心；逐项记录的核心主题名称及正文禁用点题词；大小讲法及采用范围；拟呈现的感受；形式；成片总时长；表达方式；允许公开的范围；结尾；必须保留内容；制作条件 |
| 工作材料 | 完整题目或全文；原话与来源；已确认事实；一般示意／授权演绎；待核实项；反馈；查过的历史去重范围 |
| 确认记录 | 首轮类型和数量的实际回复或明确委托；题目选择；答案／方案的版本与确认范围；拟定观点是否经本人认可；修改授权 |
| 版本关系 | 既有项目和题目编号；首稿、当前稿、目前最好稿；来源版本；本轮改动；审核问题及状态 |

不另建一套客户编号系统。没有编号时在当前项目内建立可追踪编号，不能仅凭同名题跨客户匹配。混合批次按条保留“泛话题／原GGB分支”等路线和标准；转交、写稿、复审不能无声换路。

## 六字段内容卡

保留来源审核规则中已有的六项，用于选中题进方案、写稿交审和跨窗口接续：

1. **对象与版本：**题号、标题、当前版本，修订稿的来源版本；附当前完整稿及必要原稿／最好稿。
2. **观众与处境：**主要对谁说，在什么具体情境下听。
3. **主要目的与核心表达：**要完成的任务、采用的大小讲法、正文内容、拟呈现的感受和具体观看理由，区分已确认／提案／待确认。多个核心主题分别记录其名称，供写稿与审核检查正文禁用点题词；这是内部信息，不变成让用户重复填写的表，也不照抄进正文。
4. **确认状态：**运营选中、IP认可观点、经历真实性、方案确认分别记录，不能互相替代。
5. **可用材料：**事实、原话、表达参考、来源归属与允许范围；假设和待核实项另标，作者自评不是事实。
6. **表达边界与反馈：**有效形式、时长或明确不限时长、口吻、公开范围、引导要求；须原样保留的具体文字及后来解除锁定的范围；已认可／否定的具体原句、修改理由、反复未解决的问题及对应版本。

字段可以与上表合并记录，不要求复制两张表。完整正文必须一起传，不用摘要代替正文。交接卡和作者自评能说明任务意图，不能证明正文已兑现。先读正文判断实际交付，再带回材料核对事实和限制。

## 事实与确认分别记录

- 每项材料保留归属、性质、来源／位置、核验情况、适用条件和允许使用范围。未知记未知，不适用的字段省略。
- 运营者口述、独立查证、IP认可立场、允许公开、小洋认可稿件和真人试拍是不同证据。
- 模拟角色的拟定观点不能转写成真实人物原话；授权一般情形示意不等于允许编亲历。
- 确认须能对应题目、版本或清楚的范围。“都看看”仅批准当轮候选；选中一题不等于批准尚未写出的方案；同意修改不等于认可未来修改稿。
- 要求更新 Skill 或发布规范，不等于认可上一版脚本。未明确通过的改稿保留待反馈状态，不作为推荐样稿、通过正例或真人任务验收；有效反馈可提炼为通用规则，角色和故事不进入通用默认。
- 上层已确认的对应方案直接承接。仅修一个词不重启确认；调整核心结论时先回报具体变化，其他未受影响确认继续有效。
- 初次入口未明确回复时，GGB 状态保留待确认：子 Skill 返回所缺的路线／数量选择，不自行接受1＋1提议。

## 按动作更新

选题后保留编号、核心、观看理由、依据和去重范围，候选不是用户选择。选中后进方案时再整理完整内容卡，不给所有未选候选附长表。

方案后记录其版本和实际待确认内容；确认之后写稿，并记录来源方案。审核后记录结论、证据、问题状态和当前最好版本；修改后核对仍有效要求并更新全文。

审核问题可记“已解决／部分解决／未解决／新增／误判撤回”。最新版有实质退步时保留原稿或回退相应段落；不为了保留旧审核结论而继续改坏。

## 统一返回

每次返回包含当前产物、一个执行状态、更新后的必要交接、实际未解决项和下一动作。

| 执行状态 | 含义 |
| --- | --- |
| 已完成 | 本轮动作完成；不代表用户认可、可以开拍或流量已验证 |
| 部分完成 | 已有可用产物，数量或覆盖未满；列目标、实际、缺额和真正原因，不凑数 |
| 待补信息 | 缺决定性事实或条件；交回已能完成部分与最少具体问题 |
| 待确认 | 首轮范围、答案、方案或核心变化尚待用户选择；交具体询问或可审阅方案 |
| 需转交 | 请求超出本 Skill，返回已有产物和边界，由调用方接续 |
| 依赖不可用 | 入口／必要规则不可读，指出缺项，不假称成功调用 |

审核结论独立为“通过／局部修改／需要重新诊断”。例如审核动作可已完成而稿件需要重新诊断；事实材料不足时只报告范围明确的文本初判，正式判断待补。

不要循环调用上层，不让调用方和子 Skill 对同一缺口各问一次。无缺口不制造提问，只有可选润色时允许停止。
